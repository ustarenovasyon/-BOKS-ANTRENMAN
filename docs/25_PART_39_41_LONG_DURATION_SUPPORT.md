# PART 39–41 — Duration policy support

The three duration extensions are implemented as one coherent support-layer change, so all five added durations receive the same curriculum, role, length, defense and progression treatment. This is a single lockable PART, not three partially activated production changes.

The enum now names all eight durations. Production generation and the creation UI retain their explicit V1 1/3/6 gate until PART45. No long-duration program is claimed as production ready in this support-only PART.

Curriculum and stage-local footwork resolvers use the central long-term timeline for new durations and explicitly defined intermediate/experienced levels. Original beginner 1/3/6 boundaries remain identical. Stage 5/6 use the existing strike/defense/footwork universe; no movement is invented. Support rounds retain 2–3 punches; main ceiling remains 6, challenge ceiling 7, 8+ is excluded from V2.

Long progression includes five phases with weights 5/10/15/40/30 percent, bounded work duration, strength tiers and existing weekly focus balancing. Recovery-cycle application and persisted task objectives are connected at the joint activation gate. Every fourth long-program week reduces task intensity, not elapsed session duration.

The old PART36 assertion that intermediate has no timeline was replaced by an assertion for its now explicit stage-2 timeline. Historical V1 fingerprints are untouched. A seven-day weekly metric loop was bounded to one complete week; previously it never terminated when all weekdays were selected.

Validation: all 24 duration/experience combinations, contiguous exposure transitions, role/length limits, defense eligibility 0/2/4/4/4/4, footwork eligibility, phase totals and 7-day metrics, plus existing V1 suite, independence, typecheck, lint and build.
